# AngleMaze graphics upgrade — implementation entry point

Create a cohesive, illustrated 2D mathematical adventure based on the owner's supplied in-game reference: detailed bright foliage, stacked orange timber mazes, the recognizable memorial protagonist, stone golems, an amber exit, expressive animation and an accurate optional Protractor. The earlier muted grass, single-plank walls and oblique player walk atlas did not meet the reference and are being superseded: runtime now targets the supplied foliage/wall style and the project's supplied overhead `player.png`. The physics body remains authoritative.

## Constraints that must survive implementation

- Physics owns player travel; the visual root follows the body every frame. Never replace travel with a destination tween. Current movement is velocity plus a timer, not exact endpoint interpolation.
- World remains 800×600; right = 0°, up = 90°, positive turns counterclockwise. Screen Y increases downwards.
- Player body is 20×20, straight walls are 8 units thick, diagonal walls use chains of 8×8 bodies. Preserve these and both fixed level datasets.
- **Enemy sprites have no AI or attached bodies, but Level 2 has tiny wall segments at their positions.** These are stationary collision hazards that cause ordinary wall-hit life loss. Preserve the exact segments and response; add no patrol or targeting.
- Exit art and physics are now separate objects. The invisible trigger takes its bounds from the rendered legacy art, preserving the measured themed and fallback activation areas.
- Preserve move counts, lives/checkpoints, timer and save callbacks, registration, navigation and desktop/mobile command handling.
- Preserve the memorial character and prosthetic side. Never mirror the character to manufacture opposing directions.
- Reference sheets are not production sprites. The reviewed grass/wall/golem/exit images are first integration candidates, not final art approvals. The existing compass is commented out.
