# Preserved source art

`grass-reference-v4.png` is the original approved 1254 × 1254 grass color master. Runtime serves the visually reviewed q96 JPEG export at `frontend/public/assets/premium/environment/grass-reference-v4.jpg`; the aligned normal map stays in the public asset directory as PNG.

The master is kept outside Vite's public directory so production builds do not package both color versions. Do not edit this file to tune runtime compression; export a new versioned runtime image and retain this original as the reference.

SHA-256: `A8591F3AD5714E9B4B775839C8440657AEF0BCCC91EE482F3247BF990742B2ED`

`player-walk-cycle-v2-original.png` preserves the original transparent 1254 × 1254 four-frame walk atlas. Runtime uses a reviewed 384 × 384 resample with 192 × 192 frames; this source copy preserves the authored-resolution master for future edits.

Other historical concepts and superseded art moved out of `frontend/public/` after a source search found no runtime references. Their archive copies were SHA-256 checked before removal. This keeps Vite's production asset output focused on the currently selected art while retaining the source options here:
